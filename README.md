# 📊 Análisis Exploratorio de Datos: New York Stock Exchange

## 📝 Descripción del Proyecto
Aplicación web interactiva desarrollada en Python orientada al Análisis Exploratorio de Datos (EDA) del conjunto de datos históricos de la Bolsa de Nueva York. El proyecto evalúa la salud financiera de múltiples corporaciones a través de indicadores de ingresos, rentabilidad, liquidez y apalancamiento, utilizando filtros dinámicos y visualizaciones estadísticas sin recurrir a modelos predictivos.

## 🚀 Instrucciones de Ejecución (Local)
Para ejecutar este proyecto en tu propia máquina, sigue estos pasos en tu terminal:

1. Clona este repositorio:
   `git clone https://github.com/Zander-Delgado/final-proy-DMC.git`
2. Instala las dependencias necesarias:
   `pip install -r requirements.txt`
3. Ejecuta la aplicación de Streamlit:
   `streamlit run app.py`

## 🗂️ Variables Principales (Diccionario Breve)
| Variable | Descripción |
| :--- | :--- |
| **Ticker Symbol** | Símbolo bursátil que identifica a la empresa. |
| **Period Ending** | Fecha de cierre del período financiero reportado. |
| **Total Revenue** | Ingresos totales de la corporación (escalado en miles de millones). |
| **Net Income** | Utilidad neta o pérdida tras deducir gastos operativos e impuestos. |
| **Total Assets/Liabilities** | Volumen total de activos y pasivos (indicador de apalancamiento). |
| **Current/Quick Ratio** | Ratios de liquidez a corto plazo para evaluar viabilidad financiera. |
| **Profit Margin** | Margen de utilidad porcentual. |
